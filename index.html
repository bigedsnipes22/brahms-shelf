Something else at LoC

A /resource/ address carries the ID. A bare item number needs the API, which may be blocked from here — if it is, set a page count and missing pages just drop out of the sheet.

Saving on iPad: open the image, then Share → Save to Files. Save to Photos re-encodes it and you lose the point of pulling a TIFF.

The mapping: the sp= number in LoC's own viewer is the image number — sp=19 is image 0019. The manuscript's written page numbers are a separate sequence; for the Third Symphony image = written page + 2, verified against image 0020 carrying the hand-numbered 18. Other items haven't been checked.

Page counts and identifiers were read from the LoC API item by item, not inferred. The Violin Concerto's corrected solo part (Brahms and Joachim) is listed in the research guide but its API record 404s, so it isn't here.
